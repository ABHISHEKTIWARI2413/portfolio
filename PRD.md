
# PRD: Abhishek Tiwari — Personal Portfolio Website

## 1. Project Overview

Build a premium, modern, responsive personal portfolio website
for Abhishek Tiwari, a BTech Data Science student.

The website should showcase education, technical skills,
projects, certifications, achievements and contact information.

The design should look professional enough for recruiters,
internship applications and professional networking.

## 2. Main Goals

- Create a strong professional online identity.
- Showcase technical skills and projects.
- Highlight AI, Data Science and software interests.
- Make it easy for recruiters to contact me.
- Provide a downloadable resume.
- Make the portfolio responsive on all devices.

## 3. Target Audience

- Recruiters
- Internship providers
- Software companies
- Hackathon organizers
- Developers and technology professionals

## 4. Design Requirements

Theme: Modern and Premium

- Dark background with subtle gradients.
- Black, charcoal and white color palette.
- Purple or blue accent colors.
- Premium typography.
- Smooth animations.
- Glass-like cards used selectively.
- Subtle hover effects.
- Professional spacing and alignment.
- Minimal but visually impressive layout.
- Fully responsive design.

Avoid:
- Excessive animations.
- Unnecessary gradients.
- Cluttered layouts.
- Generic AI-generated website appearance.
- Fake testimonials or achievements.
